# 😄 Daily Mood Tracker

A desktop application built with Python and Tkinter that allows users to track their daily moods, save notes, and view mood history.

## Features

- Select mood using emojis
- Add personal notes
- Save daily mood records
- Store data using SQLite
- View complete mood history
- Simple and user-friendly GUI

## Technologies Used

- Python
- Tkinter
- SQLite

## Project Overview

This application helps users monitor their emotional well-being by recording moods and notes daily.

Available moods:

😄 Happy  
😐 Neutral  
😢 Sad  
😡 Angry  
😴 Tired

## Installation

```bash
git clone https://github.com/yourusername/daily-mood-tracker-python.git
cd daily-mood-tracker-python

python mood_tracker.py
```
